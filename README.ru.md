# Avatar of Nature — Boss Duel

Avatar of Nature — Unity-прототип, построенный вокруг понятной дуэли с боссом: игрок изучает намерение Аватара, переживает телеграфируемые атаки, разрушает сектора арены и использует открывшееся окно уязвимости, чтобы нанести урон боссу.

Проект пока является сфокусированным прототипом для Windows, а не законченной игрой. Главная цель — исследовать читаемость encounter-дизайна, позиционное давление и боевой цикл, в котором решение задачи на арене важнее, чем постоянная стрельба.

## Запуск прототипа

Скачайте последнюю Windows-сборку со страницы [GitHub Releases](../../releases).

1. Распакуйте архив в локальную папку.
2. Запустите `AvatarOfNature.exe`.
3. Выберите сложность и начните дуэль.

Управление:

- `WASD` — движение
- Мышь — прицеливание
- Левая кнопка мыши — стрельба

Начальная сцена — `AvatarBossShowcaseBootstrap`. Она показывает выбор сложности, а затем загружает `AvatarBossDuelArena`.

## Цикл сражения

- Прочитайте телеграф босса и займите безопасную позицию.
- Используйте сектора арены, чтобы реагировать на текущий паттерн атаки.
- Накапливайте stagger, пока босс защищён.
- Разрушьте сектор, чтобы открыть окно уязвимости дуэли.
- Стреляйте в открытое зелёное ядро, пока окно не закрылось.
- Достигните второй фазы, где тайминги и параметры атак становятся сложнее.

В дуэли есть атаки Earth, Fire и Shockwave, разрушаемые сектора арены, профили сложности, weak points, stagger, переход между фазами и HUD, показывающий текущее состояние боя.

## Структура проекта

- `Assets/AvatarOfNature/Runtime/AvatarBoss/` — логика босса, арены, атак, конфигурации, представления и вспомогательных систем.
- `Assets/AvatarOfNature/Scenes/BossDuel/` — стартовая сцена, showcase-сцена и арена дуэли.
- `Assets/AvatarOfNature/Tests/Editor/` — специализированные тесты Unity Test Framework.
- `Documentation/BossDuel/` — дизайн, чеклист реализации и исследование валидации.

Подробная карта подсистем находится в [`Assets/AvatarOfNature/README.md`](Assets/AvatarOfNature/README.md) и [`Documentation/BossDuel/README.md`](Documentation/BossDuel/README.md).

## Сборка из исходников

Требования:

- Unity `6000.3.11f1`
- поддержка Windows 64-bit

Откройте проект в Unity и используйте сцены из `ProjectSettings/EditorBuildSettings.asset`. Для повторяемой сборки Windows из командной строки:

```powershell
& 'C:\Unity\6000.3.11f1\Editor\Unity.exe' `
  -batchmode -quit -nographics `
  -projectPath 'C:\path\to\AvatarOfNature' `
  -executeMethod AvatarOfNatureBuild.BuildWindows64
```

Helper записывает плеер в `Builds/AvatarOfNature-Windows64/`. Результат сборки намеренно игнорируется Git и распространяется через GitHub Releases.
